# V0 verification

V0 is the gate before **archiving** the C++ bootstrap repository: the language
toolchain runs on the VM path, Shadow parity holds, and a defined native smoke
manifest matches the VM on exit codes.

**V0 is not ADR completion.** Passing V0 does **not** mark [0014](decisions/0014-compilation-toolchain-architecture.md)
M2–M4 or [0015](decisions/0015-llvm-backend-roadmap.md) toolchain-native phases done.
Those ADRs remain the long-term plan; V0 only freezes bootstrap once the gates below
are green in CI.

| ADR milestone | Status at V0 | Notes |
|---------------|--------------|-------|
| M0 (Klos, `kinglet build`) | Done | Ref `compiler.kbc` via stamp |
| M1 (KIR, `--ir`) | Done | Goldens + bootstrap recorder |
| M2 (`kinglet prove`, CI prove tier) | Done | `test-prove` job |
| **M3** (toolchain `core/main.kl` → native, no kbc hot path) | **Not done** | `kinglet build --backend native` fails on `io`/`fs`/`sys` |
| M4 (per-module stamps + link) | Not done | Post-M3 |
| Native smoke manifest (0015) | Done at V0 | 11 cases; not full regression / not toolchain binary |

## Gates (must pass)

| Gate | Command | What it proves |
|------|---------|----------------|
| Fast suite | `bash scripts/ci/run-tests-fast.sh` | Ref build, VM host, goldens, exec, regression, property |
| Prove | `bash scripts/ci/run-tests-prove.sh` or `./kinglet prove` | Self-host fixed-point `S3 == S4`, bootstrap `compiler.kbc == S3`, differential behavior |
| Native smoke | `bash scripts/ci/run-tests-native.sh` | Bootstrap with LLVM; `tests/native/manifest.txt` (11 cases) exit parity vs VM |

Local one-liner after building bootstrap:

```bash
bash scripts/ci/run-tests-fast.sh
bash scripts/ci/run-tests-prove.sh
bash scripts/ci/run-tests-native.sh
```

## In scope for V0 execution

- **VM**: full self-host compiler (`compiler.kbc`) on `backend/vm/`
- **Native**: user programs covered by the smoke manifest (integers, control flow,
  strings, arrays, structs, simple enum `match`)
- **Ref compiler**: bootstrap C++ for `kinglet build`, `--ir`, `--native` on smoke cases

## Out of scope (post-V0)

- Native compile of `core/main.kl` (needs `io` / `fs` / `sys` on native)
- `try` / `catch`, `?:` error propagation on native
- Self-host `codegen/native.kl` (native lowering stays in C++ Ref for now)
- Rewriting `backend/vm/` in Kinglet (planned later)
- Consolidating Ref into main repo (`backend/native/`, `backend/rt/`) — at archive time

## After V0

1. Tag `kinglet-lang/bootstrap` as a frozen reference (critical fixes only).
2. Move native lowering + runtime into the main repo under `backend/native/` and
   `backend/rt/` (see [native.md](native.md)).
3. Point `KINGLET_BOOTSTRAP` at the main-repo Ref binary or a vendored snapshot.
4. Resume ADR work toward **M3** (toolchain native) and remaining native features
   (errors, multi-module link, `io`/`fs`/`sys` on native).
